# 西门子杯锅炉控制笔记｜PCS7 + SMPT1000

面向 **CIMC“西门子杯”流程行业自动化方向** 的技术资料库，围绕 SMPT1000 自然循环锅炉与过热蒸汽对象，整理 PCS7 控制方案、开车顺序、PID 调试思路和 IO 地址。

适合先了解锅炉控制的结构，再对照自己的 PCS7 工程做方案整理与调试记录。**当前仓库主要是 Markdown 笔记和资料清单，未提交可直接导入运行的完整 PCS7 工程，清单中的原始 PDF 与图片也尚未上传。**

## 这里讲什么原理

锅炉控制需要同时处理“按什么顺序开起来”和“运行时怎样保持稳定”：

- **SFC 顺序控制**：组织上水、通风、点火、升压和供汽等阶段，每一步记录动作、转移条件与保护条件。
- **CFC 控制回路**：围绕汽包水位、燃油与风量、炉膛压力、蒸汽温度及压力/流量组织连续控制。
- **PID 与串级投运**：记录设定值来源、手动/自动切换、主副回路关系，以及负荷变化时的调试思路。
- **运行约束**：在产量、燃油消耗、含氧量和稳定性之间评估控制效果。

以上是笔记覆盖的控制思路；其中数值、顺序和保护条件仍应对照赛题、原始对象资料与实际工程核实，不能视为已验证的投运方案。
